# BookMyStay App

BookMyStay App is a hotel booking management system designed to simulate real-world hotel reservation workflows using Core Java and data structures. The application allows guests to search and reserve rooms, manage add-on services, track bookings, and maintain live inventory with first-come, first-served booking allocation.

The project demonstrates practical implementation of collections, queues, maps, sets, and object-oriented design through modular use cases. It also focuses on preventing double-booking, maintaining inventory consistency, and supporting scalable booking operations.

---

## Features

* Room inventory management
* Real-time room availability checking
* First-come-first-served booking system
* Unique room allocation and reservation confirmation
* Add-on service management
* Booking history and reporting
* Dynamic pricing and inventory updates
* Prevention of double-booking
